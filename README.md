## 📋 Tasks

### ✅ Task 1 — Number Guessing Game Pro

**Concepts:** `Math`, constants, input handling, `if/else`, ternary, counter

**Features:**
- Random number generated between 1–100
- User keeps guessing until correct
- Tracks number of attempts
- Smart hints based on how close the guess is:
  - 🔥 **Very close** — within 5
  - 🙂 **Close** — within 10
  - ❄️ **Far** — more than 10 away (with high/low direction)

**Files:** `index.html` · `index.js` · `style.css`
